SUBIR SIMUPLC V35 A GITHUB

1. Extrae el ZIP.
2. Abre la carpeta SimuPLC-HMI-Profesional-V35-PWA.
3. Sube TODO su contenido a la raíz del repositorio y reemplaza los archivos anteriores.
4. Confirma que existan:
   index.html
   service-worker.js
   manifest.json
   assets/js/webusb-serial-v19.js
   assets/js/hmi-global-control-v22.js
   icons/
   hardware/
   .well-known/assetlinks.json
   .nojekyll
   CNAME
5. En Android: cierra la PWA, elimina la instalación anterior, abre el dominio en Chrome, concede USB y vuelve a instalar.

Usa siempre el mismo dominio HTTPS configurado en CNAME.
