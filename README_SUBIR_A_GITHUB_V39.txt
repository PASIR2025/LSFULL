SUBIR V39 A GITHUB

1. Extrae el ZIP.
2. Sube todo el contenido interior de SimuPLC-HMI-Profesional-V39-PWA a la raíz del repositorio.
3. Reemplaza los archivos existentes.
4. En Android elimina la PWA anterior y los datos del sitio antes de reinstalar.
5. Usa USB / OTG — Automático. En Chrome 148 o superior se seleccionará Web Serial nativo.
