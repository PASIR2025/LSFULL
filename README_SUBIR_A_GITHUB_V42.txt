SUBIR V42 A GITHUB

1. Extrae el ZIP.
2. Abre la carpeta SimuPLC-HMI-Profesional-V42-PWA.
3. Sube TODO su contenido a la raiz del repositorio.
4. Espera la publicacion de GitHub Pages.
5. En Android elimina datos del sitio y reinstala la PWA para activar la cache V42.
6. Genera y carga nuevamente el codigo Arduino: debe indicar SIMUPLC HMI READY CODE V42.
