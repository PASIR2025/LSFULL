SUBIR SIMUPLC V18 A GITHUB

1. Reemplaza todo el contenido del repositorio por el contenido de esta carpeta.
2. Verifica especialmente:
   - index.html
   - service-worker.js
   - assets/js/webusb-serial-v18.js
3. Conserva assets/js/hmi-codegen-v17.js porque el generador V17 sigue siendo el firmware compatible.
4. Publica GitHub Pages.
5. En la tablet, cierra todas las pestañas de SimuPLC y borra los datos del sitio o reinstala la PWA para eliminar la caché V17.
