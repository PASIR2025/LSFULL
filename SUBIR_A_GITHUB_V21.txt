SUBIR SIMUPLC V21 A GITHUB

1. Descomprime el ZIP.
2. Sube el CONTENIDO de la carpeta SimuPLC-HMI-Profesional-V21 a la raíz del repositorio.
3. Reemplaza todos los archivos existentes.
4. Verifica especialmente:
   - index.html
   - service-worker.js
   - assets/js/hmi-global-control-v21.js
   - assets/js/webusb-serial-v19.js
5. No elimines webusb-serial-v19.js: contiene la conexión Android que ya funcionaba.
6. Después de publicar, borra los datos del sitio o desinstala temporalmente la PWA anterior.
7. Abre nuevamente la página mediante HTTPS.
8. Selecciona HMI, FÍSICO o AMBOS.
9. Regenera el código Arduino.
10. Verifica que el .ino contenga SIMUPLC HMI READY CODE V21.
11. Carga nuevamente el .ino en Arduino.
