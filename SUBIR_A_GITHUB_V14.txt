SUBIR V14 AL REPOSITORIO

1. Descomprime el ZIP.
2. Entra en la carpeta SimuPLC-HMI-Profesional-V14.
3. Sube TODO el contenido a la raíz del repositorio.
4. Confirma especialmente estos archivos:
   index.html
   service-worker.js
   assets/js/hmi-codegen-v14.js
5. Elimina del repositorio, si todavía existen:
   assets/js/hmi-codegen-v12.js
   assets/js/hmi-codegen-v13.js
6. Después de publicar:
   - cierra la PWA;
   - borra los datos/caché del sitio o desinstala la PWA anterior;
   - abre nuevamente la web;
   - verifica que el generador muestre: Generador HMI V14 activo.

VERIFICACION DEL CODIGO
El código descargado debe contener:
  SIMUPLC HMI READY CODE V14
  Serial.begin(HMI_BAUD_RATE)
  hmiProcessCommand
  hmiSendState
  READY_CODE_V14

Si vuelve a mostrar solamente "Arduino codegen (COMPACT)", el navegador todavía está ejecutando una versión antigua.
