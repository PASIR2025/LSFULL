SUBIR SIMUPLC HMI V43 A GITHUB

1. Extrae este ZIP.
2. Entra en la carpeta SimuPLC-HMI-Profesional-V43-PWA.
3. Sube TODO su contenido a la raiz del repositorio y reemplaza los archivos anteriores.
4. Espera a que GitHub Pages termine de publicar.
5. En Android desinstala la PWA anterior y borra los datos del sitio una sola vez.
6. Abre la web en Chrome y conecta el Arduino.
7. En PROTOCOLO debe aparecer: SET / STATE - Web Serial Android.
8. Genera nuevamente el codigo y verifica: SIMUPLC HMI READY CODE V43.
