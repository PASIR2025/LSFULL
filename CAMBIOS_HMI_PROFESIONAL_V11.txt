SIMUPLC HMI PROFESIONAL V11 - COMUNICACION EXTERNA

- Se agrego selector de conexion: Simulacion, USB/OTG y Wi-Fi/Internet.
- Se implemento Web Serial para Arduino por USB desde PC o Android compatible con OTG.
- Se implemento adaptador WebSocket para ESP32, modulo Wi-Fi o servidor remoto.
- Protocolo compartido SET / STATE v1.
- El HMI envia entradas I y recibe estados I/Q del controlador.
- Iniciar envia RUN,1 y Detener envia STOP sin desconectar el equipo.
- Se agregaron heartbeat, solicitud de estado y deteccion de perdida de comunicacion.
- Se agrego reconexion automatica para WebSocket.
- Se incluyeron ejemplos Arduino USB y ESP32 WebSocket.
- Se incluyo guia de conexion y protocolo.
- Se mantuvo el modo Simulacion sin cambios.
