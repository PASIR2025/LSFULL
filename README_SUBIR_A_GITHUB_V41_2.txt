SIMUPLC HMI V41.2 — SUBIR A GITHUB

1. Extrae el ZIP.
2. Abre la carpeta SimuPLC-HMI-Profesional-V41_2-HMI-Free-Pro.
3. Sube TODO el contenido interior a la raíz del repositorio donde está el index.html.
4. Reemplaza index.html y service-worker.js.
5. Conserva todas las carpetas assets, icons, hardware y .well-known.
6. No cambies la URL de Apps Script: esta versión ya usa la misma API existente.
7. En el celular o tablet, cierra y vuelve a abrir la PWA para recibir la nueva caché.

PRUEBA FREE
- Sin licencia, el indicador debe decir HMI FREE.
- Deben funcionar las plantillas de arranque directo, inversión, estrella-triángulo y tanque.
- Se deben poder colocar como máximo 2 tanques.
- Un tercer tanque debe mostrar el aviso Pro.

PRUEBA PRO
- Activa una licencia existente.
- El indicador debe cambiar a HMI PRO.
- Deben desbloquearse banda, cilindros, sensores avanzados y plantillas Pro.

IMPORTANTE
La conectividad funcional de la V41.1 se mantuvo intacta.
