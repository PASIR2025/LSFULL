SIMUPLC HMI V43 - CORRECCION DEL GENERADOR ARDUINO

CAUSA REAL ENCONTRADA
1. La interfaz mostraba "Solo HMI", pero el código generado continuaba usando:
   hmiInputSource={2}  // físico O HMI
2. La interfaz anunciaba generador V21/V22, pero el archivo .ino mostraba READY CODE V18.
3. El actualizador del generador omitía por error la versión V18 en su expresión de búsqueda.
   Por eso la corrección de modo global nunca se aplicaba al código actual.
4. El código arrancaba con HMI_START_ON_BOOT=false. Después del reinicio USB del Arduino,
   hmiControllerRunning quedaba en false y el loop forzaba Q1 apagada hasta recibir RUN,1.
   En PC RUN,1 llegaba; en la ruta USB Android podía no quedar aplicado.
5. Al cambiar el modo global desde Ladder, la regeneración podía llamar al generador FBD.
6. La lista de polaridad de salidas solo buscaba salidas FBD y mostraba erróneamente
   "No hay salidas Q" en un circuito Ladder que sí tenía Q1.

CORRECCIONES V43
- El actualizador reconoce READY CODE V18 y lo convierte a READY CODE V23.
- Solo HMI queda realmente integrado como HMI_DEFAULT_CONTROL_MODE=1.
- HELLO y el primer SET arrancan el scan si no hubo un STOP explícito.
- STOP se conserva hasta recibir RUN nuevamente.
- SET solicita scan inmediato y actualización de estado.
- La regeneración respeta el editor Ladder activo.
- La polaridad de Q usa también las etiquetas Ladder recuperadas del iframe.
- Se cambió el archivo a hmi-global-control-v23.js para evitar caché de versiones previas.
- Nueva caché PWA V43.
- Se incluye PRUEBA_I1_Q1_GENERADOR_V43.ino.
