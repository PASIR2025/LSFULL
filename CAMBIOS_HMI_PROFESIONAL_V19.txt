SIMUPLC HMI PROFESIONAL V19 — USB ANDROID MULTICONTROLADOR

CORRECCIÓN PRINCIPAL
- La V18 solo podía abrir correctamente dispositivos USB CDC-ACM.
- Aunque mostraba filtros CH340, CP210x y FTDI, no configuraba esos chips.
- En Android, el modo automático podía intentar Web Serial, cuyo selector aparecía vacío en algunos equipos.

V19
- En Android, USB/OTG Automático utiliza directamente WebUSB.
- Controladores integrados:
  * CDC-ACM
  * CH340 / CH341
  * CP210x
  * FTDI
- Identificación visible de producto, driver, VID y PID.
- Reutilización de permisos USB ya concedidos.
- Nueva página diagnostico_usb_android.html.
- Mensajes de error específicos por placa/controlador.
- Service Worker renovado para impedir que se conserve el controlador V18.

COMPATIBILIDAD
- El protocolo HMI SET / STATE no cambió.
- El código Arduino V17 que ya funcionaba en laptop sigue siendo válido.
- No es necesario regenerar el código solo por esta actualización USB.
