En Diseño puedes arrastrar directamente el nombre sin mover el componente. También puedes ajustar su posición y giro aquí.
NO: envía 0 en reposo y 1 al accionar. NC: envía 1 en reposo y 0 al accionar.
2 posiciones: la variable principal vale 0 o 1. 3 posiciones: usa una variable para la posición 1 y otra para la posición 2; el centro mantiene ambas en 0.
Sensores digitales del tanque: puedes usar un electronivel de nivel bajo y otro de nivel alto. Cada sensor tiene su propia variable y puede trabajar como contacto NO o NC. Si dejas una variable vacía, ese sensor no se muestra ni genera señal.
En automático, las bombas y válvulas siguen controlando el proceso, pero la barra lateral también permite intervenir el nivel. El sensor BAJO se considera detectado cuando el líquido alcanza su altura y el sensor ALTO cuando alcanza la altura superior. NO: reposo 0 / detectado 1. NC: reposo 1 / detectado 0. En Salida bomba (llenado) puedes escribir una o varias bombas: por ejemplo Q1 o Q1,Q2.
Señal analógica: usa etiquetas como AI1, PID1, PWM1 o AO1. Los sensores y consignas escriben en una entrada AI; los indicadores y actuadores leen el valor calculado por FBD o Ladder.
Configuración efectiva: pendiente de una variable PLC.
Configuración sin conflicto: deja Automática para que el HMI use el rango configurado en el bloque PWM/AO del programa. En un tanque analógico, Variable PLC es el nivel (AI), Variable PLC 3 es el llenado y Variable PLC 4 el vaciado. El HMI normaliza siempre el mínimo a 0 % y el máximo a 100 %. Usa una escala manual solo cuando la señal provenga de un equipo externo sin metadatos del proyecto.
Digital: Variable PLC hace subir la puerta y Variable PLC 2 la hace bajar. Analógico: Variable PLC fija directamente la apertura: 0 % cerrada y 100 % abierta. Los finales superior e inferior pueden regresar como entradas PLC.
La velocidad modifica la animación del proceso. El cilindro sigue las salidas de extender/retraer y la banda sigue su salida de motor. En la banda puedes decidir si la caja reaparece en la entrada y si desaparece al final. En el cilindro puedes mover el inicio de los sensores retraído y extendido.
El tamaño rápido ajusta el elemento automáticamente sin necesidad de escribir ancho ni alto.

Cómo funciona

El HMI envía entradas como SET,I2,1. El controlador responde con STATE,I1,1,I2,0,Q1,1. En PC, celular y tablet usa Web Serial nativo cuando está disponible. WebUSB V19 queda como alternativa para navegadores o placas que no expongan Web Serial.

USB/OTG: abre la app mediante HTTPS y toca Conectar para autorizar el puerto. Si la app instalada no muestra WebUSB, usa “Abrir en Chrome”. Wi-Fi: usa la dirección ws:// del ESP32 en red local o wss:// cuando exista un servidor seguro por internet.
