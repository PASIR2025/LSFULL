SUBIR SIMUPLC V31 AL REPOSITORIO

1. Descomprime el ZIP.
2. Sube TODO el contenido de la carpeta SimuPLC-HMI-Profesional-V31-PWA a la raíz del repositorio.
3. Conserva las carpetas .well-known, assets, hardware e icons.
4. Conserva manifest.json, service-worker.js, .nojekyll y CNAME.
5. No subas la carpeta contenedora como una subcarpeta adicional si tu web actualmente carga index.html desde la raíz.
6. Después de publicar, abre la app una vez con internet. El nuevo service worker V31 reemplazará la caché anterior.
