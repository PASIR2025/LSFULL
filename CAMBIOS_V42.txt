SIMUPLC HMI PROFESIONAL V42

- Generador Arduino unificado READY CODE V42.
- Modo inicial configurable: HMI, FISICO o AMBOS.
- Cambio de modo en tiempo real mediante MODE,HMI / MODE,PHYSICAL / MODE,BOTH.
- Confirmacion ACK para SET, RUN y MODE.
- Reintento automatico de SET si Arduino no confirma.
- El registro TX se muestra despues de completar la escritura serial.
- DTR/RTS controlado al abrir Arduino Uno por Web Serial.
- Estado inmediato ante cambios y respaldo cada 1000 ms.
- Timeout de seguridad de 15 s y keepalive continuo durante Operacion.
