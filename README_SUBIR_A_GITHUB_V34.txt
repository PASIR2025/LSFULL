SIMUPLC HMI PROFESIONAL V34 — SUBIR A GITHUB

1. Extrae el ZIP.
2. Abre la carpeta SimuPLC-HMI-Profesional-V34-PWA.
3. Sube TODO su contenido a la raíz del repositorio.
4. Reemplaza los archivos anteriores, incluyendo assets, service-worker.js e index.html.
5. No elimines las carpetas icons, hardware, assets ni .well-known.
6. En el celular, cierra completamente la PWA.
7. Abre la web una vez desde Chrome y recarga.
8. Vuelve a abrir la PWA instalada y prueba USB/OTG.

La V34 usa nuevamente el controlador WebUSB Serial V19 comprobado en la V30.
