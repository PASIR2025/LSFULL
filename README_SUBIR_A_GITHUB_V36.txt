SIMUPLC HMI PROFESIONAL V36 - SUBIR A GITHUB

1. Extrae el ZIP.
2. Abre la carpeta SimuPLC-HMI-Profesional-V36-PWA.
3. Sube todo su contenido a la raíz del repositorio y reemplaza la versión anterior.
4. Conserva las rutas de assets, icons, hardware y .well-known.
5. Espera a que GitHub Pages publique.
6. En Android, elimina la PWA anterior o borra los datos del sitio antes de instalar nuevamente.
7. Prueba primero desde Chrome usando el dominio HTTPS y después instala la PWA.

Archivos críticos actualizados: index.html y service-worker.js.
