SIMUPLC HMI PROFESIONAL V40 - CORRECCIÓN ANDROID RX/TX

- En Android Chrome 148 o superior se fuerza Web Serial nativo, incluso si quedó guardado el modo WebUSB de una versión anterior.
- Se migra automáticamente la configuración V39 WebUSB al modo USB/OTG automático.
- WebUSB queda únicamente como respaldo forzado.
- WebUSB V20 reinicia correctamente las interfaces al reabrir el puerto.
- Lectura CDC-ACM ajustada al tamaño real del paquete USB para evitar conexión aparente sin respuestas STATE.
- Recuperación automática de endpoints USB en estado STALL.
- Espera de reinicio del Arduino aumentada en Android antes de HELLO/GET_STATE.
- Caché PWA V40 independiente para impedir que Android reutilice JavaScript V39.
- Se incluye PRUEBA_ANDROID_I1_Q1_V40.ino con RUN habilitado al iniciar para comprobar I1 -> Q1.
